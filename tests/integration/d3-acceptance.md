## 一、口径（先看这三条）

1. **API 注入 200 / 根 HTML 200 / 构建通过，各自只能证明各自层面**，都不能替代浏览器点击。
2. **结构完整性通过 ≠ 内容审核通过**：证据齐备（`provenance.evidence` 非空）只说明引用闭合，不等于语文学预期已审核。
3. **跨书金标准预期先写成待核草案**，依据充分并获得确认后才 `approved`；**不从 API 输出反抄真值**。

## 七、288 字位（96×3）覆盖计划

- 三首共 96 字位；三库合计 288。
- 每字位需两列：**有效候选依据是否齐备**、**语文学预期是否已审核**。
- 当前只有平水三首能取到 `poem.tokens`（含 tone），词林/新韵因 503 取不到。
- 跨书预期（同一字在三库的归部差异、古入声 vs 现代本调）**一律先写待核草案**，等 A 的数据与 B 的读音齐备后再逐格确认，不从 API 反抄。
