- 每核实一条：在对应规则卡/本文件记录**可访问 URL 或纸质书版本 + 章节**（能定位到条目即可，页码不确定就不写页码），把状态改为 approved，并注明核实人与日期。
- 只有人工核实过的条目才能进入 `provenance.sources/evidence` 的发布来源集合；未核实条目不得作为确定结论的依据。
- 代码实现通过独立验收 ≠ 文献审核通过；两者分开记录。
