# 典籍馆与推敲台

2026-10-21：用户授权新增古典分区、全诗评议，以及诗境检索、同韵寻字、推敲笺、对读。

## 入口与行为

- `/#library`：第三分区「典籍馆」，沿用校诗台/藏韵阁的连续园景与减弱动态设置。首次进入时按需加载用户提供的2022篇作品，合并本机导入；扩展资料不可用时保留三首基础示例与本机作品。
- 诗库：题名/作者/原句搜索、选集/文类/朝代筛选、收藏、分页、JSON/JSONL 导入与 JSON 导出。点击题名阅读完整原文、显示现代普通话逐字注音、查字、加入对读或送往校诗台赏读。注音以正文摘要和Unicode码点逐行校验，不匹配不显示；未注音的「𪩘」保留原字与缺音标记。
- 长篇按句读分为有明确编号的研读选段，送入校诗台和推敲笺时保留选段题名；不将选段结论当作整篇。已识别的《庖丁解牛》使用文学赏读，不送入格律判断。其他文类未核定的作品保留未定状态。
- 诗境：按最佳相邻诗句匹配原文与预置意象词，避免长篇反复出现弱相关词而霸占前列；再把最多40首、每首不超过2000字的候选送给 GLM 排序。界面显示本库和实际候选范围；不是全库向量检索。返回引句必须逐字出自对应原诗，校验失败则提示重试。
- 对读：桌面左右并排，窄屏上下阅读；可选择两首、交换左右，由 GLM 比较意象、情绪、结构、节奏和对仗。更换作品取消旧请求并清除旧分析。单篇超过2000字时保留阅读，暂不提供AI对读。
- 校诗台「推敲台」：整诗分析完成后默认自动全诗评议，可切换侧重点及写作/赏读。原诗赏读保留古人原作；写作模式可采纳建议，每次记录得失并重新分析。
- 同韵寻字：选具体句末字位及其真实韵书候选，按韵部分页查字；GLM结合全诗筛选本页前120条候选，可试用并复查，也可跳转藏韵阁查来源。同部只说明所选韵书归部，不保证语义适合或整诗合律。
- 推敲笺：保存原稿、此版、时间和原因；支持手动存笺、JSON导入/导出、恢复版本。采纳、恢复及撤销/重做均留记录；最近80笺保存在本设备。撤销/重做栈只在当前会话有效。

## 诗库导入

支持 JSON 数组、`{"works":[...]}`、`{"poems":[...]}`，或每行一首的 JSONL。每批最多10MB，合并后最多10000首。整批先校验，失败不覆盖旧库。正文和简繁异体保留；内容去重忽略空白，来源URL不同的版本分别保留。

```json
[
  {
    "title": "作品题名",
    "author": "作者",
    "dynasty": "朝代",
    "paragraphs": ["第一段原文", "第二段原文"],
    "source": "实际底本或采集来源",
    "sourceUrl": "https://实际来源域名/作品页面",
    "tags": ["实际主题标签"]
  }
]
```

`title`与非空正文必填；正文也可用字符串 `text`/`content`。`author`、`dynasty`、`source`、`sourceUrl`、`tags`可省略，缺省来源显示导入文件名，不自动生成文献依据。URL只允许HTTP(S)。单篇总长最多20000字、最多200段、每段最多2000字。导出保留完整作品和来源；收藏另存本设备。诗库用IndexedDB，推敲笺用localStorage；清理浏览器数据会移除本地记录，迁移前可导出备份。

## 模型与接口

复用服务端 `ZHIPU_API_KEY` / `ZHIPU_MODEL`（默认 `glm-5.3-flash`），Key不进入前端。文学请求与辨音共用并发、超时和断开取消机制。无Key、网络错误或模型内容不符时显示错误，原文、韵书查字及已存推敲记录仍可用。

- `POST /api/v1/poetry-assistant`：`critique` / `search` / `compare` / `rhyme`，请求与响应共用 `packages/contracts/src/studio.ts` 的Schema。响应SHA-256绑定解析后的请求；前端验证后才显示。
- `POST /api/v1/rhyme-words`：韵书、真实候选ID、offset、limit，返回同组非原字的分页候选和原有证据。未修改任何审核状态。
- `GET /api/v1/library`、`GET /api/v1/library/{id}/pronunciation`：可离线读取的扩展正文与逐字注音。加载失败不影响既有分析服务。
- `GET /api/v1/character-reference/{char}`：独立的广韵与现代读音参考，在藏韵阁字条底部展开。区分原字条目和明确关联字形，不将简繁异体的古音证据混为一字；程序映射不替代三书格律证据。

改字建议须使用真实字位、原文完全一致、同句且只替换汉字；赏读不得返回改字。同韵推荐的目标须为当前诗文句末字，其候选和所荐候选必须属于真实数据与同一韵部。诗境结果只允许已提供的作品ID、无重复ID、原诗内的逐字引句。文学评价和改字优劣仍属AI参考，结构校验不能保证文学判断准确。
