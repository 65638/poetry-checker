# DeepSeek语料与读音参考

2026-10-21，按用户“开始改”接入其提供的古诗注音与汉字读音资料。来源文件只读；仓库存留压缩后的原样字节，不执行提供者的爬虫或安装脚本。

## 页面

- 典籍馆首次进入加载2022篇作品，支持原文、来源链接、逐字查字、选集/文类/朝代筛选、收藏和现代普通话注音。提供资料的“唐诗三百首”主选集320篇，包含交叉标签时筛出321篇，保留实际标签。
- 长篇原文完整可读，研读按编号选段进行，每段受2000码点及解析句数限制；推敲笺保留选段标题。已识别的散文《庖丁解牛》走文学赏读。其他作品不据提供者“全诗库”声明强填文类。
- 诗境按最佳相邻句匹配，不按整篇出现次数累加；“雨夜思乡”本地首位为《夜雨寄北》，“江上孤舟”能召回《江雪》等。GLM仍只排序最多40篇候选，不宣称向量检索。
- 藏韵阁字条下方可展开“广韵与现代读音参考”，原字与关联字形分开查询。该参考独立于平水、词林、新韵判定，不改原候选ID或审批状态。

原始留存：`data/raw/deepseek/*.gz`。派生产物：`data/library/deepseek-v1/*.json.gz`。所有原始字节摘要、压缩摘要、派生摘要及订正记录在 `data/raw/deepseek/manifest.json`，根来源清单通过 `supplementaryManifests` 引用它。

三篇超过200个原始段落的长篇仅合并相邻段落以适配作品结构，原换行保留。显示注音前重新验证正文SHA-256、作品ID和每行Unicode码点数。标点及未提供读音用null保留；《望海潮·东南形胜》的「𪩘」没有注音，页面不猜音。

参考层共五条订正记录：乾的古寒切/渠焉切今音配反分别改为gān/qián；樂的三条反切与今音对应不充分，取消逐条现代读音绑定，保留上方独立字典读音池。其他条目的今音与古音对应仍只供参考，不能据本批结构验证宣称语言学全量正确。

语料包含近现代作品。正文、选集与注音的来源权利未独立核实，不承接提供者的版权或人审保证；页面保留逐篇来源链接和参考提示，不声称全部可商用。

## 复现

从已提交快照离线检查，无第三方Python依赖：

```powershell
python scripts/data/import-deepseek.py --check
```

省略`--check`重建派生文件。只有首次取入用户提供的原始目录时使用：

```powershell
python scripts/data/import-deepseek.py --source 'C:/Users/21393/Documents/deepseek-harness/default-workspace'
```

```powershell
pnpm verify
node --import tsx tests/e2e/corpus-reference.mjs artifacts/corpus-reference
node --import tsx tests/e2e/poetry-studio.mjs artifacts/poetry-studio
node --import tsx tests/e2e/library-atmosphere.mjs artifacts/library-atmosphere
```

新增数据接口不调用外部模型，已有本机依赖即可离线运行查阅。重新安装依赖是否可离线完成仍取决于本机包缓存，不能与运行离线混为一谈。缺少本批文件时扩展接口返回明确503，既有分析/健康检查照常；前端保留基础示例与本机作品。
