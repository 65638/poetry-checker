# 阅读与推敲

## 典籍馆

题名/原句检索支持用空格连接多个条件，如 `李白 明月` 同时查作者与正文。可用 `作者:`、`题名:`、`朝代:`、`正文:`、`标签:` 限定范围；`明月 -题名:静夜思` 排除指定题名，双引号用于完整短语。检索不改变原作的简繁字形；诗境模式仍按意象召回后交给模型排序。

打开一首作品后，它会进入「最近读过」，保留最近12篇。刷新页面后展开此处即可回到原诗；此功能记录作品，不记录上次滚动位置。不同底本的条目分别保留。

原诗上方的「复制整首」包含诗题、作者、朝代、完整正文及来源，适合发给他人；「下载诗文」生成同样内容的 TXT 文件。分享不夹带内部模型状态、输入摘要或请求快照。复制受浏览器权限限制时，界面会提示使用下载或手动复制。

右下角「字号」在标准、较大、大字之间切换，作用于原诗、对读、等待时的诗文与推敲笺对比。「静读」调暗背景景物。两项选择在本机保存，刷新后沿用。

打开作品后，文末的「同题串读」会根据正文中实际共现的词或作者，列出可接着读的作品与原句。可只看收藏，打开原诗，或送入两诗对读；点“比较”才会调用 AI。串读中可返回上一首。

## 提问与接续讨论

校诗台的「带着问题读诗」和典籍馆的「问问这首诗」可直接填写问题。选示例只填写问题，点击“就此提问”才发送。原诗赏读讨论古人作品，写作推敲才提供可采纳的改字建议。

提问和追问输入框支持 Ctrl + Enter（macOS 为 ⌘ + Enter）发送。普通 Enter 仍然换行，中文输入法确认和按住快捷键不会误发；等待时可继续写下一题，需等当前请求结束后再发送。选段阅读的示例问题只针对当前所选文字。

原诗每段旁的“问这段”会把该段原句带入问题框，可修改问题后再发送。短诗结合全文，长诗自动选择该段所在的研读范围，并在问题中注明“当前选段”；较长原段只引用开头，不声称已研读整篇。点击入口本身不会调用模型。

回答下方的「围绕这份回答继续追问」携带同一份原文、研读条件与最近最多三轮回答。总评完整带入，可取之处、改字原因与取舍过长时发送摘录，并明确标注。展开“追问所依据的回答”或“本次追问参考了…”可查看实际引用背景。AI 的旧回答仍可能有误，不作为文献或格律证据。

同诗同条件的新问题等待、失败或取消时，上一份回答仍可阅读；其标题、复制和收藏都对应那份已完成的回答。切换诗文或检查条件会重新隔离结果。最近六条回答可在“回看本次研读”切换，切换会停止当前等待；刷新前请收藏重要内容。

两诗对读中的「带着问题对读」可专门比较结尾、意象或表达方式。每次带入当前左右原诗与所填问题，不会自动带入旧对话；若提到此前回答，请在问题中补充具体说法。同一对原诗的回答可回看、收藏与分享；“重新回答这个问题”重做当前显示的问题，尚未发送的草稿不会混入。交换或更换诗作后清除本次对读历史与问题框，已收藏的结果仍保留。

长于 2000 字符的作品，在对应卷的「AI 对读范围」先选择一段，可展开查看实际发送的文字，原作全文仍保留在下方。左右可各选一段，或以一段对照另一首短诗全文。换段不会自动调用模型；换段后旧答案清除，交换两卷时所选段随原作交换。等待、回答、收藏和分享都标明选段编号，选段比较不能代表整篇结论。

## 研读收藏与分享

回答旁点“收藏评议”，然后点“查看这份收藏”可直接打开对应记录。页面下方“研读收藏”支持按问题/原句查找、按赏读/推敲/两诗对读/改稿对照筛选，也可改标题和撤销。这里保存的是当时的原文、问题与回答，不会替换当前草稿。

在收藏中可继续追问，新的回答可另存一份；原收藏保留。打开收藏本身不会调用模型，离线时也能阅读已存内容。更换设备或清理浏览器前，导出完整备份；这些收藏存在当前浏览器和网址下。

两诗对读或改稿对照的收藏也能直接提新问题：沿用当时保存的左右文字、选段范围或修改意图，不必重新找诗，也不会把当前编辑稿混入。此入口只带原文与新问题；若针对旧回答，请在问题中写清具体说法。最近回答可回看，满意后另存。

“复制评议”与“下载评议”默认只分享当前问题、原诗与回答，适合发给他人；需要讨论过程时勾选“分享时附上此前问答”。收藏和完整备份保留本次问答及其实际引用背景。不能把最近三轮背景当作无限长的完整聊天记录。

## 推敲笺

在校诗台下方打开「推敲笺」，可按诗句或修改原因查找，也可只看有改动的记录。展开「原稿与此版」可并排看完整文本、逐行查看增加和删除；插入一行不会把后面未变的诗句都标成修改。

「恢复此版」回到该条记录的修改后版本；「恢复修改前」回到该条的原稿。恢复会另存一条笺记，保留修改轨迹。「复制此版」只复制诗文。最多保留最近80笺，重要作品可使用原有的导出笺记功能备份。

「改稿对照」可选择旧稿与新稿，先查看全文和逐行改动，再填写修改意图并让 AI 比较表达得失。选稿、查看差异和输入意图不会发送请求。评议可收藏或分享，保留两版原文与意图；新稿不一定更好，也不把表达评议当作合律判定。

## 等待与重试

全诗评议、诗境、对读和荐字等待时显示计时；可取消，再点「重新研读」。失败后可点「重试本次研读」，不必清空或重填诗文。

如果 AI 总评完整，但个别改字建议缺少必要内容或与原文字位不符，页面保留评议并说明隐藏了几条建议；这些说明也会随收藏和分享保留。整个回答不完整时仍提示重试，不补造缺失内容。

相同输入重新请求时，之前成功的研读结果仍可阅读；新结果返回后替换。换了诗文、韵书或任务条件，不把上一首诗的结果冒充新结果。采纳改字仍保留旧分析并标明待更新，修改完再集中分析。

客户端最多等待105秒，为服务端90秒的 DeepSeek 模型阶段留出返回本地结果的余量。重试是新的模型请求；界面不在背后循环调用。格式未确定时，评议保留条件说明，不为了合律替多音字换读音。

## 本机备份与恢复

页面底部可展开「本机备份与恢复」。导出包含当前草稿、稿匣、已经保存的导入诗库、诗作收藏、摘句与笔记、字笺、推敲笺、研读收藏、阅读记录、字号/静读/动态设置；只读取网站约定的记录，不导出浏览器里其他项目的数据或服务端模型密钥。系统自带的诗库仍由网站提供，无需每次复制整库。

选择备份后先校验文件，再点击「预览合并」。确认后合并已有记录并去重。默认保留当前草稿与阅读设置；需要替换时分别勾选。恢复草稿后可用推敲台的撤销返回原输入。修改在本页生效，无需刷新。

相同编号但内容不同的作品/笺记会提示冲突，不静默覆盖；超出80笺、1000首收藏、24个收藏字等既有上限会停止合并。文件上限20MB，超过时使用原有分项导出/导入。校验不符或预览后本机数据变化时不写入，需重新选择文件或预览。导入诗库事务失败时回退本次设置写入；浏览器存储本身故障导致回退失败会明确提示，备份文件应继续保留。

完整备份包含自己的诗文与记录，请保存到自己选择的位置。导出完成只表示浏览器已生成下载；建议在换电脑或清理浏览器前检查文件确实保存。

## Windows 桌面启动

已有依赖与构建时，在项目目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/desktop-start.ps1
```

脚本优先使用本机已有的 Codex Node 运行时，再查找 PATH 中的 Node。运行已构建网站不需要 pnpm；首次安装依赖或更新页面构建仍需要 `pnpm install --frozen-lockfile` 和 `pnpm build`。模型配置从项目根目录 `.env.local` 读取，不放在桌面脚本里。

默认页面为 `http://127.0.0.1:56106/`，API 为56107。重复打开复用自己已启动且健康的服务；发现前端构建、API源码、规则/数据、模型配置或运行依赖版本变化时，重启自己的服务。端口被其他程序占用时改用空闲端口并打印实际网址，不结束占用者。

桌面入口将构建文件复制到本机发布快照再启动。开发时重跑 `pnpm build` 不会直接替换正在使用的页面；验证完成后再次运行桌面脚本才发布新版本。快照不包含源码或 `.env.local`，脚本检查文件完整性和JS资源能否加载。静态快照损坏会重新复制；原始构建缺失仍需先构建。后端仍由当前项目启动，更新源码后应通过桌面脚本重启。

浏览器记录与网址绑定，尤其是主机名和端口。切到备用端口不会迁移原地址下的诗库、收藏和笺记；原地址恢复后记录仍在。迁移机器前请导出备份。

诊断日志在 `%LOCALAPPDATA%\PoetryChecker`。需要停止此脚本启动的服务时：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/desktop-start.ps1 -Stop -NoPause
```

脚本核对项目路径、Node 路径、PID 和创建时间，只停止匹配的主进程及其 API 子进程。此入口用于本机预览，不是远程网站部署或独立安装包。
