# 藏韵阁与自选诗句查阅

导航中“校诗台”用于整诗分析，“藏韵阁”用于查字；切换保留当前草稿和报告。两处使用同一真实韵书接口，查询功能不依赖整库 readyz 为200。

## 已实现

- 一个汉字查平水、词林、新韵的全部候选，展示声类、候选平仄、韵部、已有现代读音/反切、证据和来源。缺失字段如实显示未载，不推造释义或选音。
- 三书对照保留各书独立结果与失败；传统古音和普通话不混算。
- 诗句拆为不同汉字；单批最多96个不同汉字，四个并发请求。逐字速览区分已核候选、待核、未收录、请求失败。“已核”不代表整诗合律或语境读音确定。
- 校诗台可把当前诗句直接带到藏韵阁。单字查询15秒、逐字查阅30秒超时可重试；编辑、切书和新请求使旧响应失效。
- 字笺收藏最多24条、最近查询最多12条，均只存本机汉字和韵书身份，重新打开会查当前数据。校诗台草稿另存本机，恢复时不恢复报告或人工选音覆盖。
- 条目和查询链接可复制。`#dictionary?char=月&book=pingshui` 可直接进入对应字；链接查询当前服务版本，不锁定历史结论。
- 月下纸笺与月洞门延续现有色板；切换有轻微横移/远景变化。关闭动态或系统减少动态时停用过渡，隐藏的校诗台暂停雨景绘制。375/768/1440布局可用。

## 接口和边界

复用已有 `GET /api/v1/characters/:char?book=` 与 LookupResult，无新增公共Schema，也不改冻结CheckerViewProps。来源接口 `GET /api/v1/sources/:sourceId` 现在提供已装载来源及其证据，未找到404、资源冲突503，审核状态保持原值。

三库查询按不可变快照对象复用索引，WeakMap不按版本字符串串用。可变调用输入不缓存，返回容器修改不能污染下一查询，原始记录依旧冻结。候选事实、ID和审批范围均不变。

词林新增16候选的批准在独立PR #28；本功能分支以main@cea831b开发，不能把该分支原有词林0批准状态误说成PR #28丢失。集成时两批均需保留。

查字可浏览真实未审核候选；整诗分析仍执行证据门槛。没有把未审核数据改成approved，也没有用查询速览冒充格律分析。

## 复现

```powershell
pnpm verify
node tests/e2e/dictionary.mjs artifacts/acceptance/dictionary
pnpm test:e2e
```

独立浏览器脚本启动隔离端口和自己的浏览器profile，不停止现有预览服务。并发迟到、503和15秒等待使用CDP受控网络；正常查询和恢复均走真实API。未覆盖的完整人文审校、真人审美反馈和多浏览器兼容性不算通过。
