## 2. 三套韵书的缺口

### 平水韵

- 实有 105 部：上平 15 / 下平 15 / 上 28 / 去 30 / 入 17；应有 上 29。
- 缺：**上声三讲**。补缺依据（维基文库）本机不可达，故 `data/patches/pingshui-shang-sanj-jiang.draft.json`
  只记录缺口，`proposedCharacters: null`，**没有补任何字**。
- 原表内部重复：85 个韵部里存在同字重复（例如“一东”里“同”“筒”各出现两次），
  导入时按“同字同部”去重：原表条目 10,671 → 候选 10,378。
- 多归部：1,823 个字出现在两个及以上韵部（“中”在“一东”与“一送”等），全部保留，不压平。
- 反切 / 义项 / 今读 / 古今关联：源表不含 → 一律 `null`，未生成。

### 词林正韵

- 19 部 / 33 子卷（第 1–14 部各分平/仄，第 15–19 部只有入声），归属 5,575 条 / 字形 5,037。
- 只标仄声的记录保留 `ze_unspecified`，**没有**擅自补成上/去。
- 韵目名：源表只给 `第N部`，没有“东钟”“江阳”之类韵目名；要不要补名列为待核实。
- 与维基文库《詞林正韻》的正文对照：**未做**（页面不可达）。
