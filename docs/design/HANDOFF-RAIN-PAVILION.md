## 已实现的体验

**指针**：四枚 24×24 本地 SVG，用浏览器原生 cursor/hotspot 显示。场景中为浅色小水滴，纸面为墨色水滴，可操作控件为细环与中心点。热点均为 12,12，立即跟随 OS 指针，无 JS 跟随，无 cursor:none。输入框保留文本 I-beam，禁用控件保留 not-allowed；强制颜色模式恢复系统指针。旧的 96px 跟随光晕及相关事件循环已删除。

**环境**：原有山水上加入层次不同的微雨，月色稍暗，山间雾带更明显。顶部细瓦檐、两侧窄立柱和纸面下的木质案沿构成前景；边缘偶尔有较重的檐滴。装饰全部代码原生 SVG/CSS/Canvas，无生成图片、视频背景、新依赖或远程资源。

**雨的响应**：静止鼠标附近形成小范围分流，移动速度产生局部横风，雨丝根据风与距离弯曲。停止移动后风势衰减，环境雨继续。控制范围约 118–170px；不移动纸面或点击目标。鼠标在输入/控件/报告/证据/页眉页脚范围内不驱动雨；触摸、取消、离开窗口、文字选择和滚动清理局部响应。

**江面**：雨滴到水域后产生小椭圆水纹；直接点击水域产生较大的双圈涟漪。总水纹最多 24 个，其中主动点击最多 2 个、间隔至少 250ms。水域是画面下方江面的近似几何范围，不是全屏点击特效。小水纹可能在被不透明纸面遮挡的位置计算，但不会画到纸面上。

**阅读安静**：报告存在、正在编辑/分析或证据打开时，雨的强调系数降至 0.24。标题附近另设较弱的雨区；纸面和报告保持不透明。动态效果关、系统减少动态、强制颜色、窗口隐藏/失焦均停止雨循环；重新可见时不追赶积压时间。

## 实现取舍

- `RainField` 只有一个 rAF 调度循环，实际绘制最多 60Hz，最多 250 根雨丝；窄屏最多 90 根，像素比上限 1.5。位置和速度均留在 effect 局部变量，无每帧 React render，无每帧 DOM 测量。
- 静置时持续下雨，因此上一版「空闲 rAF=0」已经不是正确要求。相应回归改为验证静置雨持续、鼠标风势收稳，以及暂停后没有帧回调；这不是取消暂停或有界资源检查。
- 粒子、风与水纹为可控制的写意模拟，不宣称真实流体力学。原生 cursor 在 OS 层，CDP 屏幕截图不会录入它；样式、资源请求、文本/禁用语义已通过浏览器检查，最终手感应在实时预览体验。
