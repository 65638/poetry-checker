# 视觉规格（collation desk 基线 · 丰富化第 1 轮）

范围：`apps/web/src/presentation/`。所有颜色/尺寸只在 `styles/tokens.css` 定义，组件不另立色板。

## 基调
- 纸白底、墨色正文、克制的绿（平/通过）与红（违规），另加印章红仅作标题点缀。
- 不用渐变、玻璃、粒子；不新增动画。动效仍为 P1：仅 `--pc-dur-control` 120ms 背景过渡与 `--pc-dur-panel` 220ms；`prefers-reduced-motion` 时均为 0。
- 层级：诗文第一，结论与韵书口径第二，诊断与证据第三。

## 色彩 token（对比度按 WCAG 相对亮度计算，非像素实测）
- 页面 `--pc-bg` #f7f5ef + 纸纹 `public/design/paper-grain.svg`（240px 平铺）；纸纹 alpha 上限 3.5% 墨色，最深像素约 #f0eee8。
- 正文 `--pc-text` #262923：底色上 13.5:1，最深纸纹上 12.7:1。
- 次要 `--pc-text-muted` #666a61：底色上 5.07:1，最深纸纹上 4.76:1，隔行底色上 4.72:1（均 ≥ 4.5）。
- 标题双线 `--pc-rule` #8a8578：底色上 3.38:1（≥ 3）。印章 `--pc-seal` #a8362a，字用 `--pc-bg`：5.97:1。
- 结论横幅加强底色 `--pc-*-bg-strong`：通过 #dcebe3 / 违规 #fbe3df / 待复核 #fcefc6 / 不适用·未支持 #e8e4d9；对应前景色 6.29 / 5.63 / 5.69 / 6.77:1，正文均 ≥ 11.6:1。
- 原 `--pc-*-bg` 浅底保留给诊断标签与证据面板，未改值。
- 字格悬停改用 `--pc-surface-hover` #e8e4d9，避免与隔行底色 `--pc-surface-sunken` 相同。

## 字号与尺寸
- 标题 `--pc-text-display`：桌面 32px / ≤599px 26px，宋体系，字距 0.08em。
- 印章 `--pc-seal-size` 36px / 30px，字号为边长 0.6 倍，圆角 4px，装饰性（aria-hidden）。
- 页眉底线：`3px double var(--pc-rule)`（两条 1px 线）。
- 诗字 `--pc-text-poem`：桌面 28→32px（56×76 字格内约 38px 字行 + 17px 声调行 + 8px 内距 = 63px，不超出）；≤599px 保持 24px（44px 字格）。
- 结论图标 `--pc-status-icon` 32→40px（≤599px 36px），图标字 `--pc-text-xl` 24px；结论标题同为 24px。
- 逐字表行距：行间 4px，每行上下 8px 内距；隔行（偶数行）用 `--pc-surface-sunken`，色带通过负外边距 `--pc-band-pad`（12px / 8px）外扩，字格位置与可用宽度不变。

## 不变项（冗余编码）
- 结论：文字标签 + 图标形状（圆/方/圆角方）+ 颜色，三者并存，本轮只改尺寸与底色深浅。
- 韵脚「韵」、读音待定「?」徽标加 1px 白描边，在隔行底色上保持清晰；虚线框 = 声调未定；◆ = 诊断关联。
- 焦点环 2px `--pc-focus` #1d4ed8，偏移 2px，未改动。
