# 视觉规格（独特化重设计：「山·墨·诗」墨色展厅）

范围：`apps/web/src/presentation/`。颜色、尺寸、时长只在 `styles/tokens.css` 定义。完整交接（文件、命令、截图、限制）见 `HANDOFF-DISTINCTIVE-UI.md`；方向比较见 `DISTINCTIVE-UI-DIRECTION.md`。旧「校对台 / 写作台」规格已被本方向取代。

## 构图
- 顶部墨色展台（420px，≤599px 约 196px）：巨字「诗」、印章红日、三层 SVG 山峦与雾，全部 aria-hidden；「律」印（组长已确认）+ 楷体标题 64 / 52 / 34px + 竖排小字。
- 展厅 `.pc-hall`：左侧输入台（plinth）上压展台 `--pc-stage-overlap`；右侧报告手稿（manuscript）双线外框。≤899px 单栏。
- 输入框横线稿纸 + 印章红左线；主按钮印章红，忙碌时底边扫光。输入框 DOM 位置不随模式变化（焦点、IME 不受影响）。
- 批注诗文：桌面 64×80 字格 / 40px 字，768 为 56px，375 为 44px；韵脚印章红 + 双下划线。
- 批注列表：≥1280px 两栏，行距收紧（第 1 轮）。证据面板：右侧全高抽屉、墨色页眉、印章红边（手机为顶边）。

## 色彩与对比度（WCAG 计算值）
- 页面 #f4efe4：正文 14.30、次要 6.03:1。手稿 #faf7f0：正文 15.33、次要 6.46、印章红 5.59:1。隔行 #efe9db：次要 5.71:1。
- 展台 ink-900 #14181a：浅字 14.40、浅次要 6.53、印章亮红 4.80、金 7.94:1；ink-700 上浅次要 4.86:1。
- 印章白字 5.98:1。结论强底：通过 4.89、违规 5.35、待复核 5.36、不适用/未支持 7.02:1。
- 巨字、山峦、雾、横线均为装饰，不承载信息，不计入对比度要求。

## 状态冗余编码（不只靠颜色）
- 结论 = 文字「结论：X」+ 64px 盖印图标（每种状态不同形状/圆角，未支持加虚线）+ 颜色。
- 韵脚 = 徽标 + 双下划线；「?」= 读音待定；虚线框 = 声调未定；关联字格脉冲两次并带 ◆。
- 陈旧报告：整体减淡 + 虚线外框 + 文字说明，锁定逻辑不变。

## 动效（用户授权「大胆浮夸」，取代旧 140–280ms 上限）
- 开场（每次加载一次）：展台 760ms，120ms 递进延迟。
- 报告入场（`inputHash` 变化）：360ms 淡入 + 盖印 + 每行 60ms 交错，总长封顶约 650ms。
- 证据抽屉 300ms；控件 160ms；忙碌条 1100ms 循环；关联脉冲 700ms × 2。
- `prefers-reduced-motion`：所有时长 token 归零，关键帧以 `!important` 关闭；`--pc-dur-report` 仍挂在 `.pc-root` 上（e2e 读取）。

## 已知依赖与限制
- 375px 七言折行：组长已接受为 P0（可用宽 279 / 295 / 约 311px 的历史测量仍有效），字格不缩到 44px 以下。
- `html, body { margin: 0; }` 仍是唯一页面级规则。
- 楷体 / 宋体字体栈：Windows 可能回退到 SimSun，横线对齐只做过度量核对。
- 视觉评审：**待 Codex 审阅**（本会话只有文字度量自查，截图在 `docs/design/distinctive-ui/round*/`）。
