# 视觉规格（重设计第 1 片：写作台 + 批注阅读页）

范围：`apps/web/src/presentation/`。颜色、尺寸、时长只在 `styles/tokens.css` 定义，组件不另立色板。设计说明与集成请求见 `HANDOFF.md`。

## 基调与构图
- 当代诗歌写作台 + 批注阅读页：暖纸底、深墨字、克制的绿（平/通过）与红（违规），印章红仅用于「律」印与步骤序号。
- 页眉：「律」印（组长已确认，aria-hidden）+ 32px 宋体标题（≤599px 26px）+ 副题同基线，下接 `3px double var(--pc-rule)`。
- 无报告（`pc-desk--writing`）：680px 稿纸 + 三步说明；山形轮廓 `/design/mountain-contour.svg`（墨色 10–16% 透明度）只放在说明下方，不压正文。不留空报告栏。
- 有报告（`pc-desk--reading`）：稿纸收窄为 380px 并吸顶，批注诗文占主区；<1100px 两种模式都单栏堆叠。
- 输入框在两种模式下 DOM 位置不变，焦点、光标、输入法不受影响；不按报告身份加 key。
- 稿纸横线：`--pc-ruling` 按 `--pc-text-draft` × `--pc-leading-draft`（22px × 2，≤599px 20px × 2）铺设，随内容滚动。

## 色彩与对比度（WCAG 相对亮度计算值）
- 页面 `--pc-bg` #f7f5ef + 纸纹（最深像素 #f0eee8）：正文 13.53 / 12.71:1，次要字 5.07 / 4.76:1。
- 稿纸与报告页 `--pc-surface-sheet` #fdfcf8：正文 14.37:1，次要字 5.38:1，强调绿 7.56:1，印章红 6.34:1。
- 隔行 `--pc-surface-sunken` #f0ede5：次要字 4.72:1。选中批注 `--pc-accent-soft`：正文 12.81:1。
- 印章白字 6.51:1；页眉双线 3.38:1（≥3）；按下态白字 12.53:1。
- `--pc-ruling` #e6e1d4 对稿纸仅 1.27:1，纯装饰，不承载信息。
- 结论加强底色与前景：通过 6.29、违规 5.63、待复核 5.69、不适用/未支持 6.77:1。

## 结论与批注（冗余编码，不只靠颜色）
- 紧凑结论头：文字「结论：X」+ 图标形状（圆/方/圆角方，未支持另加虚线框）+ 颜色；复制、下载按钮在右侧（≤599px 换到下方）。
- 批注诗文：每联之间加 12px 间距，句号标在左侧并用横线分隔；韵脚 = 「韵」徽标 + 双下划线；「?」= 读音待定；虚线框 = 声调未定；◆ = 批注关联。
- 批注列表：编号圆圈 + 状态标签（图标 + 文字）+ 严重度 + 规则名；选中项 = 浅绿底 + 左侧 3px 竖线。
- 陈旧报告：2px 虚线框 + 「⟳」文字说明，保留原锁定逻辑。

## 动效（opacity/transform 为主；`prefers-reduced-motion` 时时长 0、位移 0、按压缩放 1）
- 140ms `--pc-dur-control`：按钮、韵书选项、字格的悬停/按下（scale 0.97）/选中过渡；批注选中底色。
- 220ms `--pc-dur-panel`：证据面板遮罩淡入、面板滑入 16px（手机为上滑）；◆ 标记出现。
- 280ms `--pc-dur-report`：仅报告入场一处使用（`ReportView.tsx` 的 WAAPI，淡入 + 上移 8px）。保留理由：简报给报告入场单列 300ms 上限，此处是唯一的「max 300」用例；只在 `report.inputHash` 变化时播放，点字、选批注、打字都不会重播；减弱动效下由 JS 判断并读 0ms token 双重跳过。
- 不做退出动画、循环、打字机效果或强制等待；忙碌态是静态圆点 + 文字，只跟随 `busy` prop。

## 375px 与已知依赖
- 字格可用宽度：GLM 实测，桌面浏览器 279px（旧 body 外边距）/ 清零后 295px / 手机覆盖式滚动条约 311px。
- 七言需要 332px，所以会折行；组长已接受为 P0 行为，字格保持 44px，不缩到可点击尺寸以下。逐行横向滚动留作 P1。
- `tokens.css` 中的 `html, body { margin: 0; }` 是唯一的页面级规则，也作用于 D 的正式入口。
- 稿纸横线与文字行对齐依赖实际使用的宋体：GLM 在 Windows Chromium（SimSun 回退）下核对已对齐；其他字体可能偏移，属已知依赖。
- 纸纹、山形以 `/design/` 绝对路径引用，默认部署在根路径；D 若修改 Vite `base`，需要同步。
