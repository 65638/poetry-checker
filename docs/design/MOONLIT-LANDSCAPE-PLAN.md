## 1. 已确定的方向与问题

组长选择 A「月下江山」，并补充：操作时也需要更优秀、细致的动画，巧妙而不突兀。

最新补充：**动效不必轻巧，允许明显的幅度和表现力；优先保证丝滑、衔接自然、不过于拖沓。** 下文的轻亮、淡入等描述只是候选手法，不是统一的低强度限制。细腻指曲线、节奏和细节精度，不等于动作幅度小。

本轮规划同时解决三件事：

1. 长诗或长报告向下阅读后，左侧空白过多、编辑入口与结果脱离。
2. 顶部黑色与下方白色硬切，缺少同一个场景的连续感。
3. 鼠标指针和背景缺乏精致互动，操作反馈只完成基本功能。

总体方向：深青夜色、银白月光、远山江面，配温润月白纸卷。表现力放在开场、边缘景物和关键操作；诗文与证据区保持稳定、清晰。已有“律”印保留，朱砂只作小面积强调；错误状态仍由文字与图标明确区分。

## 2. 统一场景，消除黑白断层

- 整页共享同一层深青至雾青的场景底色，山形跨越页眉与工作区，不在某个水平位置突然结束。
- 顶部月色与下方江雾通过宽幅、低对比渐隐区域过渡；工作区外围保持有层次的青色，报告作为独立月白纸卷浮在其上。
- 页面深处继续保留极淡远山和环境光，避免只有第一屏有景色、往下变成纯空白。
- 明显的波光、雾线与光点集中在页边及空白，正文下面保持静态、近乎不透明的阅读底色。
- 开场一次性呈现月、山、纸卷，约 600–900ms；输入和按钮无需等待动画结束即可使用。
- 素材优先使用原创 SVG、CSS 和现有资产；具体表现由实现时验证，不预设必须接入新生成服务或重型渲染库。

## 3. 长诗阅读：左侧随屏“录诗台”

### 初始态

输入区完整展示，示例、韵书和分析按钮保持首屏可用。不会为了背景效果重新引入过高头图。

### 有报告时

- 左侧成为可停靠的阅读工具栏，展示已有诗名或“当前诗作”、所选韵书、编辑/重查入口、检查统计和诗句导航。
- 先实现明确的“收起编辑 / 展开编辑”控制。若增加自动精简，只能在用户主动提交成功、焦点在编辑区外且未处于输入法合成时触发；不能因失焦就收起。允许手动保持展开。
- 输入框保留同一 DOM 节点，不用条件分支卸载再重建，以保留正文、光标位置与手动调整高度。
- 桌面工具栏在报告范围内 `sticky` 停靠，不覆盖页脚；最大高度受视口约束，必要时导航列表内部滚动，焦点项始终可见。
- 导航显示诗句序号及短句摘录，当前阅读位置用细线和淡光提示；点击跳转该句。键盘主动导航需定位焦点或播报可理解的目标位置，滚动观察本身不抢焦点、不触发自动滚动。陈旧报告的目录禁用或明确标注旧报告。
- 短诗无需为了填满左侧而堆砌组件；布局以实用内容与适当留白为准。
- 单栏及移动端取消桌面停靠，改为紧凑的“编辑 / 诗句目录”入口。不得用大片固定面板遮住正文或字格。

边界：导航和统计全部从现有报告推导，不新增格律结论；尚无作品名称时不通过 AI 猜测标题。是否需要额外业务状态，实施前以现有冻结 props 能力为准。

## 4. 鼠标与背景的联系

### 指针：月光笔尖

- 桌面精细指针设备上，采用小巧、清晰的月白指针设计，准确点击点与系统坐标同步，不制造拖拽感。
- 指针外围附加低亮度柔光圈；只有外圈允许约 60–100ms 的跟随缓动，点击点不能延迟。
- 悬停可操作控件时光圈轻轻收拢或描出控件局部边缘，按下时短暂缩小。不会把按钮吸向鼠标或挪动点击目标。
- 可采用本地 SVG `cursor` 资源并提供原生回退，不使用全页 `cursor: none`。输入框、正文选择、链接、拖动调整大小等语义光标保持可辨识。
- 离开窗口、窗口失焦、触屏、粗指针、强制色彩模式或开启“减少动态效果”时隐藏装饰跟随层，保留可靠的原生操作方式。

### 背景：三层响应

| 层次 | 自发运动 | 随鼠标变化 | 作用范围 |
|---|---|---|---|
| 远山与月色 | 原则上静止 | 约 2–4px 的低幅视差 | 场景背景，不移动文字 |
| 近处薄雾 | 缓慢、稀疏漂移 | 约 6–12px 的温和偏移 | 页边与景物留白 |
| 江面反光 | 极弱的波光变化 | 光晕随位置移动，停留或轻点背景时出现一圈短暂涟漪 | 江面区域；不覆盖表单和报告 |

所有幅度、透明度和时长均为初始设计范围，待实际看图与操作调整。控制同时存在的涟漪数量和触发频率，不在每个 pointermove 事件上创建粒子。鼠标静止后视差平滑收稳，环境动效继续；页面失焦/隐藏时环境动画暂停。

### 静止时也有生命感（组长最新要求）

背景分成互不争抢的两套运动：**自主环境动效 + 鼠标响应动效**。

- 无鼠标操作时：雾在约 18–32 秒的周期内缓慢漂移，江面碎光约 6–12 秒轻柔变化；可加月亮外缘雾晕约 12–20 秒的极轻变化。山体与月亮主体保持稳定。
- 各层错开节奏、循环无硬重置；不让整屏亮度呼吸，不自动连续生成波纹，不用漫天粒子填满留白。静看一分钟仍应适合阅读。
- 鼠标进入和移动时：在环境层之上叠加视差、水光与指针响应；停下后约 500–900ms 平滑回到环境状态，而非整幅画突然冻结。
- 输入、IME 合成或查看证据时降低环境强调；减少动态效果、关闭动效、页面失焦/隐藏或场景离屏时暂停，恢复时不补播积压帧。
- 活跃指针测量之外，另录 30 秒静置表现；保留静置→移动→静置的短视频或带时间戳的代表帧。静态截图不能证明循环自然。

以上时长为起点。优先用低成本 transform/opacity 与少量 SVG/CSS 图层；持续全屏模糊、噪声重绘或随机粒子不是默认实现。

提供可发现的“动态效果”开关，允许关闭持续背景运动和指针装饰；尊重系统 `prefers-reduced-motion`。这是新增的本地展示偏好，不改变 HTTP 契约；持久化时需适配存储不可用的情况。

## 5. 细腻的操作动画

总原则：每次操作只突出一个视觉焦点；反馈先响应用户，再完成过渡。允许明显的展开、平移、缩放、光影变化和短促回弹，以运动连续、收尾干净为标准。速度有层次，连续点击从当前状态平滑转向，不排队播放、不让动画决定业务完成时间。

节奏分层：高频控件反馈约 100–220ms；抽屉、折叠与布局转换约 220–400ms；报告展开等关键呈现约 400–700ms。开场可维持约 600–900ms。以上为可调起点，不把所有动画压成短淡入；相关动作应重叠衔接，避免串联多个阶段造成等待。内容和操作无需等装饰动画收尾才可访问。背景可保持较慢的环境运动，但不能拖慢任何操作。

| 操作 | 拟定反馈 | 初始时长 | 必须保留的行为 |
|---|---|---|---|
| 按钮悬停 / 按下 | 边缘亮起、明确的按压反馈，松开时可短促回弹；快速收稳，不反复振荡 | 100–220ms | 点击面积和位置稳定，键盘焦点同样清楚 |
| 切换韵书 | 选中背景像细窄月光滑到目标，说明文字短暂淡换 | 180–240ms | 选中值与业务状态立即更新，换书清除旧覆盖逻辑不变 |
| 载入示例 | 输入纸面轻亮一次，标题或入口给出确认 | 180–260ms | 正文一次性载入，不用打字机逐字改内容 |
| 开始分析 | 按钮文字与轻量进度线平滑切换，周边动效降亮 | 120–200ms 进入等待态 | 只依据真实 busy 状态，无虚构百分比或强制等待 |
| 收到报告 | 纸卷有层次地展开，结论与诗行交错入场；幅度可以明显，各阶段重叠推进 | 总计约 400–700ms | 失败/待复核不播放成功庆祝；不重播于选字和普通编辑 |
| 展开 / 收起编辑区 | 高度、位置与透明度连续衔接，工具栏和阅读空间一起顺势调整 | 240–380ms | 不卸载输入框；焦点在内部时先妥善处理再收起；不截断 IME |
| 诗句目录定位 | 用户点击后滚动到目标，左侧位置线与诗句边缘短亮 | 滚动遵循平台，强调约 300–450ms | 手动滚动中断自动定位；被动观察不抢焦点，主动键盘定位有可感知目标；减少动态效果下直接定位 |
| 字格悬停 / 选中 | 细边框与底色缓入，选中韵脚或关联字形成呼应 | 120–180ms | 不改变字格大小、不挤动整行；保留状态文字和标记 |
| 打开 / 关闭证据抽屉 | 抽屉带有明确空间感地滑入，遮罩与内容错峰衔接；关闭利落收回 | 开 280–380ms，关 180–260ms | 焦点约束、Escape、背景 inert、关闭后回焦顺序正确；快速反向操作从当前位置过渡 |
| 展开检查条目 | 分组平滑展开，内容轻淡入；保留原生 disclosure 语义 | 180–240ms | 高度自适应，不硬编码 max-height 裁掉长解释；键盘操作和自动展开仍有效 |
| 批注定位字位 | 目标字边缘出现一次柔和光带，并关联诗句目录 | 约 300–450ms | 不整页闪烁，不循环脉冲，不替换实际诊断颜色 |
| 复制 / 下载 | 操作完成后图标与短反馈轻换；失败仍明确显示 | 140–200ms | 成功提示由真实结果触发；旧报告导出门槛保持 |
| 错误 / 陈旧报告 | 提示条平稳出现，背景与边框切换 | 120–180ms | 不摇晃整个表单、不让错误文字闪烁、不隐藏旧报告说明 |

共同约束：减少动态效果时取消视差、跟随、缩放、空间位移及平滑滚动，用即时的文字、边框、图标和状态变化提供等价反馈。长诗的逐行入场总时长封顶，不能因行数多而延迟阅读。

## 6. 实现边界与执行顺序（供 Claude 开工）

本轮已选定方向，Claude 开工后直接实现，不再做三方案比较。原来的“两轮精修”已完成；本计划是新一轮实施，先交完整首版，再最多两轮视觉精修，每轮解决 1–3 个主要问题。功能回归修复不能因视觉轮次用完而放弃。

1. 先做统一背景和长报告工具栏，确认 900px 等中间宽度与首屏主操作不退步。
2. 完成按钮、分段选择、示例、结果、证据抽屉等状态动画；使用同一套 motion tokens，明确重播与中断策略。
3. 再加入月光指针、山雾视差与江面涟漪，控制图层数量、事件成本和持续运动。
4. 使用真实正式入口复验，捕获相同内容/视口的前后对照及动态片段；技术验证与用户审美确认分开记录。

预计工作量：布局与场景约 3–5 小时，操作动效约 3–4 小时，指针和环境互动约 2–4 小时，回归与视觉复核约 2–3 小时；合计约 10–16 小时，仅用于规划，非承诺。若工期紧，先完成前两项；后两项不得挤占数据主线和既定交付。已验收的旧样式与静态回退保持可恢复。

默认路径仍为 `apps/web/src/presentation`、`apps/web/public/design`、`docs/design`。冻结接口、请求取消、读音覆盖、证据审批、真实规则结论和导出语义均不属于此视觉计划的修改范围。实现中需要跨目录时按既有单写交接流程记录。

## 7. 未来验收标准（本次均未执行）

- 1440×900、1366×768，以及 1280/1100/1024/900/899/768/375 宽度：首屏可操作、无横向溢出，短诗和长诗均能阅读。

- 鼠标移动、快速往返、停留、离窗、键盘导航、滚轮与触摸：指针不拦截点击，背景不与内容抢注意力。实际触屏仍需单独验收。
- 操作动画可被新操作中断；旧请求不会触发新报告动画。相同文本重查、切书、失败、取消和等待时主动滚动均复验。
- 保持示例原文、选音重查、覆盖清理、复制导出限制、全部状态、IME、44px 触控下限与焦点链路。
- 系统减少动态效果、本地动态开关、后台标签页和低性能环境均有有效静态回退；实际性能在浏览器测量，不预先声称稳定帧率。
- 后续运行 `pnpm verify`、既有真实浏览器验收，并补充新交互的必要场景；本次文档更新不宣称新增功能已测试。

## 9. V2 具体设计取舍

### 构图：一幅景、两种工作状态

初始态像临江录诗：紧凑题头、左侧录入、右侧适度留白和使用引导。报告态像展卷批注：左侧变为持续可用的录诗台，右侧诗文居中呈现，下面才是重点问题与收起的已通过检查。背景贯穿页头、工作区、页底，报告纸面近乎不透明。

```text
              月光与远山：背景连续，主操作无需等开场
┌───────────────────┬────────────────────────────────┐
│ 录诗台 / 展开编辑   │ 结论与韵书口径                  │
│ 所选韵书、重查入口   │ 逐句诗文、平仄与韵脚             │
│ 诗句目录、当前句     │ 重点问题 → 已通过项折叠区         │
│ 桌面限定范围内停靠   │ 长文正常随页面滚动               │
└───────────────────┴────────────────────────────────┘
              江面与淡雾延续到页底，不再黑白硬切
```

沿用 899px 单栏分界优先；900–1100px 重点防止右侧结论被挤成窄竖条。若确需调整分界，布局与结果自动定位的条件同步修改。移动端目录采用流内折叠，不固定盖住字格。200% 缩放检查作为必要回归，不把所有文字塞进固定高度。

### 色彩与质感：从墨黑展厅转为青绿月夜

候选色：深夜 `#101F25`、远山 `#203C43`、雾青 `#7E9B9D`、纸面 `#F5F0E5`、正文 `#233238`、朱砂 `#A64135`。这是起稿方向，须按最终组合测对比度。纸面保留温度，不做透明玻璃；月光与水光只在画面空隙明显，证据正文不透景。

字号层级和留白承担主要表现力，山景是空间背景；不再通过加高巨字头图实现“高级”。印章保留一处主识别，避免每个组件都加花边、题签、光晕。示例、韵书、分析、复制、下载继续使用直白名称。

### 三个值得打磨的瞬间

1. **刚进入**：远山先建立深浅关系，月光与纸卷重叠入场；控件即时可用。
2. **分析返回**：纸卷展开、结论与诗行短暂错峰，录诗台切入阅读辅助；不因为判定 fail 而抹掉表现力，也不播放“成功庆祝”。
3. **指向与取证**：鼠标像月光笔尖，水面轻应；点字后证据抽屉明确滑入，背景安静下来。返回时焦点准确回到原字。

其余反馈围绕这三处服务，不让每个悬停都出现大幅动效。

## 10. 工程落地的关键防回归

| 风险 | 实施要求 | 验证方式 |
| --- | --- | --- |
| 长左栏 sticky 仍会超出视口 | 固定可用高度，目录单独内部滚动；编辑区独立展开；祖先 overflow/transform 不能破坏 sticky | 长报告顶部/中部/底部与页脚截图，检查实际几何 |
| 输入框切换模式丢失光标 | 保留相同节点和 React 位置，无 report/hash key；合成输入时不自动折叠 | DOM 引用、selection、composition 与焦点检查 |
| 再分析相同正文不播放/不定位 | 保留提交意图与新报告身份判断；不能只比 inputHash | 点击与 Ctrl+Enter，两次相同输入复跑 |
| 多个动画争夺滚动 | 自动定位只有一个控制方；导航只在用户主动操作时滚动 | 等待中滚轮/触摸/编辑/失败均不延迟抢回位置 |
| 抽屉关闭前就卸载 | 若要退出动画，使用展示层保留壳处理生命周期；焦点约束与背景 inert 持续到实际关闭，关闭快照禁止选音 | 快速开关、Escape、焦点返回、减弱动态效果、中断 |
| 连续鼠标动画拖慢输入 | pointermove 只记录位置，单一 rAF 写样式；无每帧 React state/布局测量；稳定后停止跟随计算 | 10秒指针/滚动轨迹，记录设备、帧时间/长帧与长任务 |
| 动效关闭后元素仍隐藏 | 系统 reduce 优先；实时切换取消空间运动并落在最终状态；存储失败可用 | 本地开关、系统实时切换、禁用存储、后台与回前台 |
| 触屏出现伪鼠标光圈 | fine/hover 和事件 pointerType 双重判断；触摸、失焦、离窗均隐藏 | 合成触摸另标；真实触屏未测则明示 |

新专项脚本写 `docs/design/moonlit-ui/`，只读复用 CDP/helper，不抢 E 的共享 runner。真实诗作验证与明确标注的长页合成 fixture 分开保存。新增素材仅用本地原创 SVG/CSS 或许可明确资产，不引入运行时外部依赖。

## 11. 交付优先级与审核口径

- **首批必须**：连续场景、初始/报告布局、长页录诗台、响应式及旧功能回归。
- **完整 UI 交付必须**：操作动画、动态开关、精确指针与光圈、至少一组随鼠标变化的远近景/水光；无法完成须明确列缺口，不能把静态换肤称为完整交付。
- **可后移**：复杂多圈涟漪、额外昼夜主题、真实流体模拟、音效、全套主题设置。无需为了装饰加入依赖。
- **最终证据**：实际 SHA、命令退出码、真实/fixture 模式、截图/动态片段、专项回归与性能记录。先完成后评审；图片未查看仍写“视觉待审”，不能靠几何测量自称“顶级”。
