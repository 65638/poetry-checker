# 录诗区跳动、分析闪烁和导航底色修复

2026-10-20，基于74760a1。用户要求修复分析后录诗区跳动，并排查其他操作；随后补充重复分析短暂显示“分析中”、偶数句导航渐变结束底色突变。

## 原因与修正

- 首次报告令录诗表单同时变更高度、字号、间距与隐藏状态。原输入框直接从178px到132px，说明通过绝对定位瞬间退出布局。现统一尺寸过渡、保持输入文字与标题字号、保持横向内边距不变；隐藏区在正常文档流中渐变到零尺寸，再通过visibility/inert限制操作。保留textarea节点、中文输入和调整高度能力。
- 表单从grid改为无gap的纵向flex，间距随区块折叠，避免display切换时额外删除grid gap。几何变化使用缓入缓出；已收起编辑器保持inert。
- 桌面滚动后展开示例曾把父容器从sticky切成static，实测顶部跳动408px。保留sticky；过长的展开表单内部滚动，移动端仍采用正常页面滚动。
- 手机上首次报告等编辑区收缩320ms及两帧余量后再定位；wheel、touch、键盘及草稿变化仍可撤销定位意图。重分析和减少动态不增加该等待。
- 实际busy状态仍立即生效，按钮立即禁用。仅视觉进度延迟160ms出现，快请求不显示；出现后至少保留320ms，避免刚显示就消失。分析期间按钮保持强调色，避免禁用灰色闪一下。
- 原导航高亮动画最终帧是透明背景，偶数句回到底层米色时突变。每句通过--pc-line-background保存自身底色，动画直接过渡回该颜色。
