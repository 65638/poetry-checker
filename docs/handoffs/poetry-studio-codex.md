## 交付与实测

- 新增统一文学助手契约与OpenAPI；实际韵书同部查字；复用GLM服务端请求、并发限制、超时与取消。
- 典籍馆：本机诗库导入/导出、去重、收藏、原文与来源、有限候选的诗境排序、两诗对读；初始仅复用现有三首正文，没有伪造爬取资料。
- 推敲台：全诗评议、严格原文字位校验、同韵语义推荐、采纳后复查；推敲笺保存前后版本与原因，可撤销、重做、恢复、导入/导出。
- 句末目标绑定tokenId，重复字也按选中句位推荐；更换文本、韵脚、页码、对读诗作或收藏检索条件时取消旧请求并清除旧建议。引句必须逐字来自对应作品。
- 保留原有全局自动辨音、余字多读音修复、800ms悬停定位和参考分析策略，没有改审核记录。
