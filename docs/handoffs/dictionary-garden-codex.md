# 藏韵阁：查字区域接管

用户于2026-10-20要求新增字典区域、适配现有UI，并有“移步换景”切换。基线 main@cea831b；分支 codex/dictionary-garden。

Codex 本批接管 apps/web 的应用入口、app/Workspace、查字业务和展示组件/样式及相关测试；原 D/Claude 暂停本批涉及文件写入。用户新需求覆盖旧任务书的暂停视觉扩展安排。复用现有 GET /api/v1/characters/:char?book=，不改冻结 CheckerViewProps、公共HTTP契约或数据审核状态。A 的16项落库仍在独立 PR #28，本分支不重复携带。

验收：三书单字查询、竞争候选与来源完整呈现、待核和未收录可区分、并发/失败无旧结果冒充、切换保留草稿与报告、手机布局/键盘/减少动态。交付后按本分支提交继续协作，禁止整包回灌旧分支。

用户随后授权在断网前约一小时内持续增加功能与优化。本批补入三书对照、诗句逐字收录速览（96不同字上限/4并发）、本机字笺/历史、草稿恢复、条目/链接复制；来源接口从已知来源固定503改为返回实际已装载来源与原证据，并更正API启动日志；lexicon按不可变快照对象复用索引。扩展写入apps/api/src/server.ts及来源HTTP测试、packages/lexicon/src/lookup.ts及缓存隔离测试，原A/GLM暂停这些确切文件写入；数据、契约和审核状态未改。

实现阶段实测：pnpm verify 60文件/788项通过；新浏览器12场景通过（真实查询/恢复，另标受控延迟、503及15秒实等）。第一轮测试曾把展开动画即时文本当完成、把新韵实际收录的𠀀当缺字，已改为等可见内容并用已知缺字“余”×词林验证；另修复临时基准脚本被lint扫描的问题。初版7场景绿不重复计入12。

索引优化性能对照：三书各500样本，27种单字查询业务字节完全一致；新韵进程内查询P95约7.42ms→0.02ms。该指标不等于全HTTP或整诗分析耗时；原始摘要和实测分布独立归档。
