## 复核发现与已修复

| 问题 | 已实施修复 |
|---|---|
| 剪贴板读取异常会被吞成空串，断言仅在非空时执行；stale 后读取异常还会回退成原值 | 权限、复制反馈、读取和内容校验均必须成功，否则场景失败；不因读不到就跳过 |
| 重用 downloads 目录，可能把上次 JSON 当作本次下载成功 | 每轮创建新的独立下载目录，必须生成本轮可解析文件 |
| 只比较 summary、数据版本和 token 数量等，遗漏规则版本、具体字位内容与请求配置 | 对导出完整 report、所有版本、完整请求快照、inputHash 和选音覆盖逐项比较；请求取自实际网络 POST |
| stale 复制若错误地再次写入同一摘要，原“剪贴板不变”比较仍可能通过 | stale 前写入不同的测试标记，必须保留该标记；同时核对明确的阻止提示 |
| stale 下载只比较 JSON 个数，漏掉覆盖现有文件或临时下载文件 | 对全部文件名及 SHA-256 做前后比较，并核对阻止导出的提示 |
| 键盘场景初始自动聚焦关闭按钮，内层 Tab 次数实际为 0 | 至少真实按一次 Tab，逐步断言焦点留在对话框，循环到关闭按钮再用 Space 激活 |
| E06 已通过但 notRun 仍写“剪贴板/报告文件内容核对” | 改为尚未覆盖的请求失败/进行中/选音后导出，保留准确范围 |

CDP 的 `text` 作为 keyDown 的字符语义保留，keyUp 不再重复携带字符。字格/详情键盘路径只使用真实按键；分析准备仍用鼠标，不把整个页面流程称为全键盘验收。

新增 9 项校验器回归（含正例与 Windows 换行兼容，其他为拒绝误报的反例）：空/不可读剪贴板、错具体体式、摘要请求韵书偷换、字位数相同但声调变化、错误规则版本、请求配置变化、外层版本元数据变化。它们由 Codex 在集成侧补充，不计成 E 的新增单元测试。
