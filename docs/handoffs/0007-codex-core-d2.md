救法首版窄模式（`*` 表示该位置允许平或仄，但未知读音仍不是已知通配）：

| 规则 | 五言 | 七言 |
|---|---|---|
| RESCUE.SELF | B 型 ZPPZP | B 型 *ZZPPZP |
| RESCUE.TEAO | C 型 PPZPZ | C 型 *ZPPZPZ |
| RESCUE.DUIJU | 同联 A/B：ZZPZZ / PPPZP | 同联 A/B：PPZZPZZ / ZZPPPZP |

七言对句救仅实现 C 矩阵列出的完整合成样例，不扩展其他前缀或变式；该材料及文献仍待 C/组长核定。规则卡仍 pending，不能因为代码实现就改为人工审核通过。首句借邻韵无已审核关系表，不自动放行；罕见救法不在本批范围。

每条 Finding 包含规则/版本、状态/等级、真实字位、预期/观察值、模板、证据 ID、解释与稳定 ID。`resolvedBy` 是规则卡 ID；`relatedFindingIds` 是诊断 ID。只有确定认可的救法且对应诊断通过时才填 resolvedBy，其他偏离继续报出。

按局部约束枚举，状态上限为 4096；公共韵部沿用交集状态上限 512。超限返回 uncertain，不随机抽样、不输出合律绿灯。

## 新发现的体裁接线阻塞（E 处理）

真实调用核心生成合成正格五绝 `ZZPPZ / PPZZP / PPPZZ / ZZZPP` 的候选：

- 第一名 wujue-ze-unrhymed：score=1，evaluatedKeyRate=1，前三特征均为 1，对仗 null。
- 第二名 score≈0.796992；分差大于 0.05。
- 选定该模板后核心报告无硬错误、押韵 pass。
- E auto 却返回 uncertain，提示 relationFit/rhymeFit 为空；实际这两项均非空。根因 featuresComplete 同时要求 parallelismFit 非空。
- 显式五绝返回 applicable，但 selectedTemplateId 仍为空：pickReliableTemplate 仅接受候选池长度为 1，而核心正常返回 4 套。
- 即使修完特征门槛，auto 高吻合分支仍明确抛 GENRE_BRANCH_PENDING；E 的 D1 测试还断言它必须抛出，需要随 D2 实现迁移。

修复应保持已批准 GENRE_THRESHOLDS 不变；不得伪造 parallelismFit=1、重算 score、偷偷从数组取第一项。按前三特征、最佳候选关键位可判率、分数及与次名分差选择可靠模板；不可靠时继续保留全部候选并待确认。显式形式与已审核近体元数据也需要可靠模板选择通路，不能因为存在 4 个候选就永久不选。

外部分发包提供 core-genre-probe.mjs：在包含各模块的仓库根目录运行 `pnpm exec tsx <脚本路径> --expect-ready`。当前失败是接线缺口；E 修复后该目标断言应通过。脚本输入全为合成测试，不得进入 API 真实分析路径。
