# 韵系与体式条件在简评中的传递修复

用户要求修复当前演示版的判读机制。基线 a0bef50，当前分支 codex/restore-current-corpus。Codex 按本次授权接管 contracts/src/studio.ts、API poetry-studio.ts、Web 简评导出、ReportView 与 PoetryDesk 的相关路径及回归测试，作为一次跨模块缺陷修复；本次会话无其他写入者，不修改韵书审核数据或格律规则以迁就样例。

已定位：AI 评议上下文丢失体式适用性与声调口径，服务端附加文案将 fail 直接写成“出律”。导出简评“应为/实际为”没有区分句式要求和韵书读音，易被理解成混用韵系。修复后以原报告条件为准，未确认体式只能作条件比较；原文、韵书、字位不一致的上下文拒绝提交模型。

回归诗文由用户提供，测试仅用作输入，不声明作者体裁或人工审定。验证结果完成后补充。
