# 编辑后自动更新

用户反馈小改动就要求重新分析、打断阅读。本批由Codex接管Web状态协调器、入口、报告/目录与推敲状态提示、相关测试；其他写入方暂停这些路径。基线main@09d3ce4。

改为首次分析后，影响结果的有效编辑在停笔1500ms后自动更新；继续输入重新计时，手动提交/取消/快照替换取消待执行更新。初次输入仍由用户开始分析，不在阅读操作时发送请求。旧报告保持可读、目录可定位；改字后的选音与导出仍以新报告为准，不混用快照。

状态协调器的自动更新为显式入口选项：生产入口与开发壳启用1500ms，独立测试/回放默认手动。仍逐字比较原文、韵书、体裁和形式，不忽略标点或空白以免破坏原文摘要和UTF-16坐标。改回已分析输入会取消待执行更新；失效的在途请求仍abort并丢弃迟到成功/失败。失败不循环重试，用户可继续修改或手动重试。自动更新调用不设置结果滚动意图，不主动把用户拉回报告顶部。
