# 阅读目录下方重叠修复

2026-10-21，基于 codex/dictionary-garden@e837091。用户截图显示展开示例与说明、清空原文后，目录和底部编辑按钮重叠。Codex 接管相关 layout/rail 样式及专项浏览器检查；原展示写入方在这些路径暂停，验证后归还。不改业务、数据或契约。

根因：sticky 侧栏设定最大高度，但编辑区不收缩，目录外壳最低仅 168px；目录内部允许收缩到零，其标题、计数和字句仍然溢出，压到最后的按钮。

修复：
- 目录及其外壳采用内容所需最小高度，字句列表保留至少一行，最大 40dvh；底部按钮与标题/列表保持独立排布。
- 编辑区和目录总高超过窗口时，整条侧栏可以滚动，不再依靠压缩目录或仅滚动表单。给木质底托、焦点边框留出内边距；小屏仍采用普通文档流。
- 无业务或组件状态改动，沿用编辑区展开收起动效。
