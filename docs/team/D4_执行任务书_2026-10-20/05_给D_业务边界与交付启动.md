基线：完整本地参考为 `feat/claude-distinctive-poetry-ui@4d39037`；编制时还未推送。Codex先发布 `origin/integrate/d4` 并广播实际SHA，不能把旧 `origin/main@05e1acb` 当完整D4代码。你可以立即在现有checkout只读盘点，但写入前需取得D4基线。自己的checkout先 `git status` 保护未提交工作；在干净且独占的checkout：

```sh
git fetch origin --prune
git rev-parse origin/integrate/d4
# 上一命令成功并核对组长广播的SHA后才执行，禁止沿用旧分支整包覆盖：
git switch -c feat/d-d4-closeout origin/integrate/d4
pnpm install --frozen-lockfile
pnpm verify
```

将d换为本卡角色小写；分支已存在先检查，不覆盖；ref未发布则立即报缺少基线SHA，继续只读任务，不自行用main替代。禁止reset/clean、重写他人提交、修改审批原件、历史证据或用当前输出反写金标准。发现新输入时由Codex完成合并，不能自行扩大写入范围。

本地最近独立验证733测试/18浏览器通过；当前API九格3通过6数据阻断，三库全量审核未完成。不能复制历史数字冒充本轮测试。合成fixture只用于明确标识的受控测试；主路径必须真实API。AI初审≠数据approved；新批次需真实接受记录，旧批次不重复问。

## 验收要求

| 用例 | 应观察到的事实 |
|---|---|
| A请求慢、B请求快且先完成 | 页面/复制/下载只对应B；A迟到成功不能覆盖，A迟到失败不能污染B |
| 请求期间编辑或换书 | 旧请求取消或忽略；draft不丢；旧覆盖不串书/串字位 |
| 候选选音→重查 | 实际POST含正确tokenId/candidateId/hash；版本与用户选择标记对应 |
| 30秒超时、网络失败、真实503 | busy退出、可恢复；保留输入；旧报告可查看但不能冒充新报告复制/下载 |
| 错误后恢复 | 新成功报告重新允许导出，摘要/JSON与实际报告一致 |
| API五类语义状态 | pass/fail/needs_review/not_applicable/unsupported如实展示；受控fixture显式标明测试模式 |
| 移动端点击或Ctrl+Enter分析 | 既有定位修复不退步；失败/编辑/主动滚动不发生迟到跳转 |

命令：`pnpm exec vitest run apps/web/tests`、`pnpm verify`。与E联合验证用当前CDP体系，不手动“看起来正常”替代请求体断言。没有真实触屏时标未运行，不以移动视口仿真冒充真机。
