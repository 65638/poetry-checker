基线：完整本地参考为 `feat/claude-distinctive-poetry-ui@4d39037`；编制时还未推送。Codex先发布 `origin/integrate/d4` 并广播实际SHA，不能把旧 `origin/main@05e1acb` 当完整D4代码。你可以立即在现有checkout只读盘点，但写入前需取得D4基线。自己的checkout先 `git status` 保护未提交工作；在干净且独占的checkout：

```sh
git fetch origin --prune
git rev-parse origin/integrate/d4
# 上一命令成功并核对组长广播的SHA后才执行，禁止沿用旧分支整包覆盖：
git switch -c feat/e-d4-closeout origin/integrate/d4
pnpm install --frozen-lockfile
pnpm verify
```

将e换为本卡角色小写；分支已存在先检查，不覆盖；ref未发布则立即报缺少基线SHA，继续只读任务，不自行用main替代。禁止reset/clean、重写他人提交、修改审批原件、历史证据或用当前输出反写金标准。发现新输入时由Codex完成合并，不能自行扩大写入范围。

本地最近独立验证733测试/18浏览器通过；当前API九格3通过6数据阻断，三库全量审核未完成。不能复制历史数字冒充本轮测试。合成fixture只用于明确标识的受控测试；主路径必须真实API。AI初审≠数据approved；新批次需真实接受记录，旧批次不重复问。

## 本轮系统缺口

- 并发迟到成功/迟到失败；请求途中编辑、切书、重复提交；检查实际最终请求/响应归属。
- 客户端真实30秒超时后恢复、禁导出；不能把仅单元假时钟当浏览器超时。受控阻塞是测试场景，在JSON明确记录模式。
- 受控五态中尚未覆盖的needs_review/unsupported；fixtures只进受控测试入口，主路径仍真实API。
- 完整键盘主任务：Tab顺序、可见焦点、示例/韵书/提交、字格、证据、候选、关闭回焦、检查折叠、复制导出。若缺跳过长区块的能力，报可操作性缺陷给D/Codex，不自行美化页面。
- 当前折叠及定位修复的必要回归：采用已有设计回归脚本的有效用例，去重后纳入统一runner；不要将两脚本重叠场景简单相加。
- 干净clone安装/构建/启动、导出数据可解析；浏览器不是根HTML200。

## 九格与金标准

| 作品 | 平水已有预期 | 词林/新韵要求 |
|---|---|---|
| 登鹳雀楼 | regulated/wujue，pass，证据闭合 | 字音按该书核定；不得复制平水逐字谱；状态以独立依据确定 |
| 静夜思 | 已批正文，ancient/not_applicable | 作品身份与音系分开；没有依据不另改正文/体裁版本 |
| 黄鹤楼 | regulated/qilv，summary仍fail；空悠悠限定特例非error | 不移植仅限平水的豁免；保留真实其他偏离与证据 |

三首每书应分别检查HTTP、Schema、全部字位、规则/数据版本、来源、读音/平仄状态及诊断，不只断言200或summary。503写阻断并附完整原因；首个503字不是全部缺口。新两库期望需由来源/已裁定规则独立形成，不能记录当前引擎输出后自动认作golden。

旧大纲12首金标准目标继续进入G09：现有3首先回归，新增作品/乐府标签需来源与审核范围。未审候选作品放review queue，不凑approved；目标不足列数目和待审原因。普通格律失败不自动古体，乐府标签不等于免检。
