## 项目上下文与统一开工规则（本卡可单独投喂）

六人五天课程项目“诗格律检查器”，仓库 https://github.com/65638/poetry-checker。本轮D4统一接收D1–D3遗留；保持已经验收的功能，暂停新的UI/动画。GLM额度不足，由Codex担任集成和技术接管，不等待GLM。

开工读 `AGENTS.md`、`README.md`、`HANDOFF.md`、`docs/ownership.md`，再读本卡指定的最新交接。历史顶部/原PR可能过时，以实际代码与证据SHA为准。Node 24.19.0、pnpm 11.25.0。公共契约、10个ruleId及CheckerViewProps冻结；没有本批明确交接的目录不修改。

基线：完整本地参考为 `feat/claude-distinctive-poetry-ui@4d39037`；编制时还未推送。Codex先发布 `origin/integrate/d4` 并广播实际SHA，不能把旧 `origin/main@05e1acb` 当完整D4代码。你可以立即在现有checkout只读盘点，但写入前需取得D4基线。自己的checkout先 `git status` 保护未提交工作；在干净且独占的checkout：

```sh
git fetch origin --prune
git rev-parse origin/integrate/d4
# 上一命令成功并核对组长广播的SHA后才执行，禁止沿用旧分支整包覆盖：
git switch -c feat/b-d4-closeout origin/integrate/d4
pnpm install --frozen-lockfile
pnpm verify
```

将b换为本卡角色小写；分支已存在先检查，不覆盖；ref未发布则立即报缺少基线SHA，继续只读任务，不自行用main替代。禁止reset/clean、重写他人提交、修改审批原件、历史证据或用当前输出反写金标准。发现新输入时由Codex完成合并，不能自行扩大写入范围。

本地最近独立验证733测试/18浏览器通过；当前API九格3通过6数据阻断，三库全量审核未完成。不能复制历史数字冒充本轮测试。合成fixture只用于明确标识的受控测试；主路径必须真实API。AI初审≠数据approved；新批次需真实接受记录，旧批次不重复问。

## 首两小时

1. 读完整九格候选清单，不仅看每个503的第一个字。列每个字位全部候选、有效候选、未审有效候选、缺字及命中语境规则。
2. 把A的48候选草案与真实快照交叉核对：candidateId/版本/字位是否一致；其余两首形成差集。独立交付B报告，不代改A批次。
3. 保留已有效的11条平水语境规则；为词林/新韵有必要的限定语境提供证据草案与反例，不平移平水候选ID或批准。

## 交付接口

路径 `data/reviews/d4/b/effective-candidates.json`；输出schema可复用原D3生成器，但需要 `baseSha`、数据/语境版本、模式、生成命令；D4产物不要覆盖历史已哈希证据。需要适配输出路径时在原脚本加兼容参数，默认行为保持，明确新增命令先实现后使用。

每行至少：`caseId, book, tokenId, character, allCandidateIds, effectiveCandidateIds, unverifiedEffectiveIds, missingSourceIds, contextRuleIds, readingStatus, toneStatus, possibleTones, blockingReason`。每个竞争候选去留有证据，统计所有有效候选的已审覆盖，不用“任一个候选有证据”冒充全部可推导。

交A的差集按“来源缺失 / 候选缺失 / ID漂移 / 未审核 / 语境不足 / 多读同调无需强选”分类。交组长的语境草案含实际短语、目标偏移、适用韵书、候选集合、语义依据、来源定位、正反例和排除范围。

## 验收矩阵

| 输入/场景 | 预期 |
|---|---|
| 已批固定句“欲穷千里目” | 里按既有四纸裁定；四寘竞争候选仍保留；相似“里外”等不得误命中 |
| 三首平水已审语境 | 当前结果保持；多读同调仍reading=ambiguous、tone可resolved，不伪称读音确定 |
| 任意含P/Z且无有效语境 | 不为合律强选，平仄未定或按证据门槛阻断 |
| 语境证据未审/错kind/来源断链/候选失效 | 不支撑选音；错误码保持冻结映射 |
| 古入声“白/一”与新韵 | 使用各自体系；不套语流变调；现代竞争读音有依据，不能按格律删掉 |
| 换书后旧candidateId或hash不匹配 | 拒绝非法覆盖，不悄悄复用 |
| 同字不同位置、多音/标点/空行/扩展汉字 | token位置、原文切片、覆盖定位准确，未知字不编读音 |
| 下游A新版本到达 | 重新核对有效候选与语境引用；旧ID必须有迁移依据，不人工重编号 |
