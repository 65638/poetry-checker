## 独立验收要求

| 场景 | 期望 |
|---|---|
| 固定平水《黄鹤楼》l4c5–7 | 仍为 PPP，TAIL.SANPING 为 not_applicable/info，resolvedBy=null，有审批引用 |
| 仅改标点/换行，分句仍受支持 | 同作品指纹，字位定位正确 |
| 正文改字、同题名/标签、传旧指纹 | 不套用特例 |
| 普通五绝/七律合成 PPP | 一般规则仍 fail/error |
| 词林/新韵，无对应批准 | 不继承平水特例；合成验证不得写成真实供数成功 |
| 审批缺失/未审、来源断链、作品依据不匹配 | 不降级；API 的加载阻断由 GLM 验 |
| 有效音歧义/未知，或目标字用户选音 | 不硬套特例；包括用户仍选平的保守边界 |
| 其它规则与字位 | 原判断保留，不改判古体，不硬改全诗 pass |
| 重复运行/冻结输入/引用闭合 | 确定、幂等、不修改输入；Schema、rule/evidence/source/位置可解析 |
