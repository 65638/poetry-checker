# 队员 A：韵书数据与机器初审任务书

## 任务目标

对三套韵书做可复现的 AI 初审，生成完整异常清单和 338 条人工抽样队列，供组长只审核异常。

## 允许修改范围

`data/raw/`、`data/normalized/`、`data/patches/`、`data/sources/`、`scripts/data/`、`packages/lexicon/`、A 的 HANDOFF 和数据质量文档。不要修改 `apps/`、`packages/prosody/`、`packages/genre/`。

## 输入

- `data/normalized/pingshui.full-d2-patched.json`；
- `data/normalized/cilin.full-d2.json`；
- `data/normalized/xinyun.full-d2.json`；
- `docs/team/18_队员A_D2_执行手册.md`；
- `docs/reviews/AI初审_人工异常复核方案_2026-10-18.md`。

## 必须交付

1. 三库机器初审 JSON/Markdown 报告；
2. 每库的部数、非空、重复、意外韵目、声类和候选数统计；
3. 候选 → 韵部 → 证据 → 来源引用闭合检查；
4. 三库来源版本、修订号、SHA 和生成器版本记录；
5. 338 条抽样审核队列：每韵部至少 2 条，另加 60 条入声/多归部/异体/名篇重点字；
6. 三讲补丁、简繁异体、新韵 `er`、轻声、未映射项异常清单；
7. 不改变原始数据事实的修复 PR。

建议输出：

```text
data/reviews/ai-lexicon-precheck-2026-10-18.json
data/reviews/ai-lexicon-precheck-2026-10-18.md
data/reviews/ai-lexicon-sample-queue-2026-10-18.json
```

## 明确口径

- 继续保留三库快照 `reviewStatus: unverified`，直到组长确认；
- 不因结构完整就声称语文学事实全部正确；
- 不删除多归部和一字多音候选；
- 中华新韵必须标注“十四韵规则 + pinyin-data 重建表，非官方原表”；
- `楼/樓` 只建立有来源的异体关系，不做无依据合并。

## 验收命令

```powershell
node --conditions=development scripts/data/inspect.ts
pnpm exec vitest run packages/lexicon/tests
pnpm verify
```

验收必须报告真实数字，不得只写“检查通过”。

## 给 AI 的开场指令

```text
你负责三套韵书的机器初审。先读本任务书、docs/team/18_队员A_D2_执行手册.md 和 docs/reviews/AI初审_人工异常复核方案_2026-10-18.md。只修改本任务书允许的目录。不要把 unverified 改成 approved，不要补造来源。先生成报告和异常队列，再修复确定的数据接线问题。每一步运行真实命令并记录结果。
```
