# 队员 E：作品元数据、体裁判断与金标准任务书

## 任务目标

固定三首作品的正文、指纹、体裁候选和异常说明，生成供组长复核的作品元数据草案；完成体裁模块在证据不足时的可解释降级。

## 允许修改范围

`packages/genre/`、`data/works/`、E 的测试、README 和 HANDOFF。不得修改韵书快照、`packages/prosody/` 或 `apps/api/`。

## 三首作品

- 《登鹳雀楼》：五言绝句候选；
- 《静夜思》：古体/古绝候选；
- 《黄鹤楼》：七言律诗候选，需保留特殊拗律和半古半律说明。

最终体裁标签必须有来源或人工待审状态，不能只凭标题、作者或是否出律决定。

## 必须交付

1. 三首作品的正文来源、版本和异文说明；
2. 用 `fingerprintText` 生成的正文指纹；
3. `data/works/metadata.json` 草案，未完成人工审核时保持 `reviewStatus: unverified`；
4. 每首作品的 `formFamily/formId/historicalTags/evidenceIds` 建议；
5. 古体/乐府提示与近体适用性说明；
6. 体裁判别异常清单：高吻合待实现、特殊拗律、正文版本冲突；
7. 三首作品的机器验收用例。

## 关键规则

- `approvedTextFingerprints` 必须由固定正文计算，不做简繁转换、不合并异文；
- 古体/乐府应输出 `not_applicable` 或明确待审提示，不强行按近体规则报错；
- `GENRE_BRANCH_PENDING` 不得吞成成功或静默降级；
- 不因格律失败自动把作品改判为古体；
- 没有来源时保持 `pending/unverified`，不要编造书名、页码和 URL。

## 验收命令

```powershell
pnpm exec vitest run packages/genre/tests
pnpm verify
```
