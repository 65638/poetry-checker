# 队员 C：格律核心、规则卡与引用闭合任务书

## 任务目标

确认格律核心的机器验收覆盖和规则引用闭合，生成供组长复核的规则异常清单。不得扩展公共规则 ID。

## 允许修改范围

`packages/prosody/`、`rules/cards/`、`rules/evidence/`、`docs/rule-sources.md`、C 的验收矩阵和 HANDOFF。不要修改 `packages/lexicon/`、`packages/readings/`、`apps/web/`。

## 固定规则 ID

```text
METER.POSITION
RHYME.COMMON
RELATION.DUI
RELATION.NIAN
GUPING.NARROW
TAIL.SANPING
TAIL.SANZE
RESCUE.SELF
RESCUE.TEAO
RESCUE.DUIJU
```

## 必须交付

1. C2-01 至 C2-13 独立验收矩阵；
2. 10 张规则卡的 `ruleId/version/evidenceIds` 检查报告；
3. `collectRuleReferences` / `checkReportClosure` 的正反例验证；
4. 三首金标准涉及的粘、对、押韵、孤平、尾式和拗救异常清单；
5. 每条文献引用的章节、页码、来源状态；
6. 明确区分“代码测试通过”和“文献人工审核通过”。

## 关键规则

- 不新增或重命名固定 `ruleId`；
- 规则卡没有可定位来源时，保持 draft/pending；
- `resolvedBy` 只能指向已存在的救法规则卡；
- `relatedFindingIds`、`tokenId`、`evidenceIds` 必须在同一报告中闭合；
- 不因为某首诗传统上被认为合律，就删除出律 Finding；
- `parallelismFit` 未实现时必须如实保持 `null`。

```powershell
pnpm --filter @poetry/prosody test

```
