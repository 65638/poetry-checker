规则集：`teaching-v1`

## 项目目标

本批采用“AI 初审 + 人工异常复核”：

- AI 负责全量结构检查、引用闭合、覆盖统计、重复构建和异常清单；
- 组长只复核多音、入声、异体、来源冲突、三首金标准关键字位和规则卡异常；
- 未经人工确认的内容继续保持 `unverified`；
- 不得把机器初审写成人工审核，不得为了让接口返回 200 而伪造 `approved`。

## 所有人先做

```powershell
pnpm install --frozen-lockfile
pnpm verify
```

如果 `pnpm verify` 失败，先记录失败命令、首个错误和当前 commit，再开始模块工作。不要用跳过检查的方式提交。

## 共同禁止事项

1. 不修改公共契约和固定 `ruleId`，除非组长明确批准；
2. 不删除一字多音、多部候选；
3. 不根据格律结果反推读音；
4. 不补造来源、页码、URL、反切或今音；
5. 不把 `unverified` 批量改成 `approved`；
6. 不把 `presentation-preview.html` 的 fixture 结果写成真实 API 结果；
7. 不修改其他成员负责目录；
8. 每个提交必须包含真实运行命令和结果。

## 统一交接格式

每 2 小时或每个可运行批次提交一次，并在 HANDOFF 中填写：

```text
完成：
修改文件：
未完成：
异常清单：
运行命令：
真实结果：
下一步：
需要组长决策：
```

## 统一完成标准

成员任务只有在以下内容齐全时才算完成：

- 代码或数据已提交；
- 单模块测试通过；
- `pnpm verify` 或明确记录未通过原因；
- 异常项有稳定 ID、来源定位和处理状态；
- HANDOFF 能让组长在不询问背景的情况下复跑。
