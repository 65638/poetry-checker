## 2. 采用口径（工程表达，待组长核定后生效）

### 2.1 基本句式与 16 套模板

- 手工基线：五言 A `ZZPPZ` / B `PPZZP` / C `PPPZZ` / D `ZZZPP`；七言 A `PPZZPPZ` / B `ZZPPZZP` / C `ZZPPPZZ` / D `PPZZZPP`。
- 八句序列（绝句取前四句）：
  - 五言仄起 / 七言平起，不入韵：A B C D A B C D
  - 五言仄起 / 七言平起，入韵：D B C D A B C D
  - 五言平起 / 七言仄起，不入韵：C D A B C D A B
  - 五言平起 / 七言仄起，入韵：B D A B C D A B
- 起式按**第二字**判定，五言与七言起式名称相反。
- 偶数句为必押韵句；首句入韵型加第 1 句；P0 近体模板使用相应平声韵脚。
- 可变位（“中”）建议教学基线：五言 A `中仄中平仄`、B `中平中仄平`、C `中平中仄仄`、D `中仄仄平平`；七言 D `中平中仄仄平平`，其余型第 1、3、5 位为“中”。**最终口径由组长核定；已发现的实现差异（七言 D 型第 3 位）见 HANDOFF。**

### 2.2 三值与未知

- 某字有效平仄集合 D、允许集合 A：D 非空且完整已知、D⊆A → pass；D∩A=∅ → fail；部分相交或存在未知有效候选 → uncertain。
- 多字规则只枚举相关位置候选组合或等价集合计算，不暴力枚举整首诗。

### 2.3 押韵

- 检查所有必押韵脚的公共归部，而非相邻两两。
- 同一个字的韵部与声调必须来自同一个有效候选；未查明的韵脚不得排除后比较剩余字。
- 只有部分合理读音配置同韵 → uncertain；全部可行配置同韵才可确定通过。
- 首句借邻韵：P0 无审核邻韵表不自动放行，提示可能涉及借韵及其限制。
- 词林正韵不因“同部含平仄”允许随意平仄通押。

### 2.4 粘对

- 同联出句/对句相对，上联对句/下联出句相粘；以第二字为主要判别点，结合五言二四、七言二四六及整句谱式。
- 先识别已认可变格，再处理其对关系检查的影响；不得认可特拗后又机械报失对。
- 每条关系输出涉及的 tokenIds 与 findingIds，供前端连线。

### 2.5 孤平与尾式

- 窄义 B 型平收句：五言 `ZPZZP`，或七言对应后五字，无相应救法时触发孤平；不是“整句只一个平声”。
- 末三字全平：三平尾 → error；末三字全仄：三仄尾 → 默认 warning。
- 未知或歧义使尾式结果依组合变化 → uncertain，不用单一默认读音下结论。

### 2.6 三类常见变格（P0 必验）

| 类型 | 最低支持形式 | 条件 |
|---|---|---|
| 孤平自救 | B 型五言 `ZPPZP`；七言对应尾部 | 指出拗位与救位；不能把所有 B 型偏离都算已救 |
| 特拗 | C 型五言 `PPZPZ`；七言“中仄平平仄平仄” | 匹配完整审核模式及约束；认可后不重复硬报 |
| 对句相救 | `ZZPZZ / PPPZP`（野火烧不尽/春风吹又生） | 出句第 4 字、对句第 3 字；七言扩展单独核定 |

- 已救时保留原偏离证据，用 resolvedBy 指向规则 ID，相关 finding 互相关联；不得把原偏离继续作为未解决 error 送汇总。
- 更宽跨句救法、罕见救法不在 P0；未在审核范围内的特殊格式不自动认可。

### 2.7 对仗边界

- P0 提示律诗颔联/颈联需要对仗；简单同位重复或词类信息只作辅助，不宣称完整语义判断，不硬编对仗置信分。

## 3. 正反例速查

| 场景 | 期望 |
|---|---|
| 候选 {P,Z} 在只允许 Z 的必检位 | uncertain，不择合律读音 |
| 韵部集合 {甲,乙}、{乙,丙}、{甲,丙} | 两两相交但全体无交 → fail |
| 甲字候选 P/乙部 与 Z/甲部，另一韵脚 P/甲部 | fail，不跨候选拼接 |
| 甲字候选 P/甲或 P/乙，另一韵脚固定 P/甲 | uncertain（部分读法同韵） |
| 一个韵脚未收录 | 不得删除该韵脚后宣布同韵 → uncertain |
| `ZPZZP` / `ZPPZP`（B 型） | 前者窄义孤平；后者自救并保留拗位/救位与依据 |
| `PPZPZ`（C 型） | 经核定特拗可识别；不重复报被认可位置失对 |
| 末三字 PPP / ZZZ | 分别 error / warning |
| 多模板并列未选定 | 待确认；只输出跨候选共同诊断，不静默取首项 |
| applicability=not_applicable | 无近体硬错误，保留查询/归部信息 |
