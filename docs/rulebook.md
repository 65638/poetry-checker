**引用规则（确认口径）**：

1. `Finding.ruleId` 必须对应 `RuleCard.id`；`Finding.ruleVersion` 对应该规则卡 `version`，首版均为 `"1"`。
2. 报告引用的普通规则与救法规则都应随 `provenance.rules` 返回，不能让前端猜规则名称。
3. `resolvedBy` 指向救法的 **RuleCard ID**（如 `RESCUE.DUIJU`），不是 Finding ID；`relatedFindingIds` 才引用同一报告中的诊断实例 ID。
4. 一条救法只解决它明确覆盖的偏离，不豁免全句或全诗其他错误；认可后保留原偏离与救位说明，将该偏离当前状态记为 pass/info 并关联救法，未解决错误照常保留。
5. 模板未确定、读音不确定时依三值语义处理，不能为填满这 10 个 ID 强造确定诊断；规则卡存在不等于对应算法已实现。

## 2. 采用口径

### 2.1 基本句式、16 套模板与可变位

- 手工基线：五言 A `ZZPPZ` / B `PPZZP` / C `PPPZZ` / D `ZZZPP`；七言 A `PPZZPPZ` / B `ZZPPZZP` / C `ZZPPPZZ` / D `PPZZZPP`。
- 八句序列（绝句取前四句）：
  - 五言仄起 / 七言平起，不入韵：A B C D A B C D
  - 五言仄起 / 七言平起，入韵：D B C D A B C D
  - 五言平起 / 七言仄起，不入韵：C D A B C D A B
  - 五言平起 / 七言仄起，入韵：B D A B C D A B
- 起式按**第二字**判定，五言与七言起式名称相反。
- 偶数句为必押韵句；首句入韵型加第 1 句；P0 近体模板使用相应平声韵脚。
- **可变位（“中”）确认口径**（“中”仅指 `expectedTones` 的基础允许集合 `[P,Z]`）：

| 型 | 五言 | 七言 |
|---|---|---|
| A | 中仄中平仄 | 中平中仄中平仄 |
| B | 中平中仄平 | 中仄中平中仄平 |
| C | 中平中仄仄 | 中仄中平中仄仄 |
| D | 中仄仄平平 | 中平中仄仄平平 |

- 七言 D 型逐位：`1 中 | 2 平 | 3 中 | 4 仄 | 5 仄 | 6 平 | 7 平`（注意一基字位与零基数组下标的区别）。
- 未知音不能当作已知可平可仄；基础匹配不能代替孤平、尾式与救法检查。
- 整诗选模板，不为每句单独挑最有利类型；不能把 C 型特拗随意换成另一句型免检。

### 2.2 三值与未知

- 某字有效平仄集合 D、允许集合 A：D 非空且完整已知、D⊆A → pass；D∩A=∅ → fail；部分相交或存在未知有效候选 → uncertain。
- 多字规则只枚举相关位置候选组合或等价集合计算，不暴力枚举整首诗。

### 2.3 押韵

- 检查所有必押韵脚的公共归部，而非相邻两两。
- 同一个字的韵部与声调必须来自同一个有效候选；未查明的韵脚不得排除后比较剩余字。
- 只有部分合理读音配置同韵 → uncertain；全部可行配置同韵才可确定通过。
- 首句借邻韵：P0 无审核邻韵表不自动放行，提示可能涉及借韵及其限制。
- 词林正韵不因“同部含平仄”允许随意平仄通押。

### 2.4 粘对

- 同联出句/对句相对，上联对句/下联出句相粘；以第二字为主要判别点，结合五言二四、七言二四六及整句谱式。
- 先识别已认可变格，再处理其对关系检查的影响；不得认可特拗后又机械报失对。
- 每条关系输出涉及的 tokenIds 与 findingIds，供前端连线。

### 2.5 孤平与尾式

- 窄义 B 型平收句：五言 `ZPZZP`，或七言对应后五字，无相应救法时触发孤平；不是“整句只一个平声”，也不能仅因两个位置为“中”就放行。
- 末三字全平 → 三平尾 error；末三字全仄 → 三仄尾 warning（不单独使全篇 fail）。
- 未知或歧义使尾式结果依组合变化 → uncertain，不用单一默认读音下结论。

### 2.6 A 型小拗（政策②：允许并标 info）

适用对象是**已确定为 A 型**的句子：五言第三字、七言第五字由常格平声变为仄声，且涉及的其他必要位置符合 A 型条件（例：五言 `ZZZPZ`，七言 `PPZZZPZ`）。

统一输出约定：

| 字段 | 值/行为 |
|---|---|
| `ruleId` | `METER.POSITION`（不增加第 11 个规则 ID） |
| `ruleVersion` | `"1"` |
| `status` | `pass` |
| `severity` | `info` |
| `locations` | 五言第三字，或七言第五字的真实 token 位置 |
| `expected` | `["P","Z"]`，忠实表达当前允许集合 |
| `observed` | `["Z"]` |
| `resolvedBy` | `null`（这是本口径允许的小拗，不假称已用救法） |
| `message` | “A 型此位置常格为平，本规则集允许用仄，作小拗说明，不要求对句相救。”可补具体句/字序号 |

- 该字位复用或更新已有 `METER.POSITION` 记录，不额外产生相互矛盾的 fail 记录；`expected` 不写成只有 P 后又直接 pass，常格与允许集合的区别用说明表达。
- 本政策**只覆盖** A 型第三字（七言第五字）小拗：不是 `RESCUE.TEAO` 特拗，也不是出句第四字（七言第六字）的大拗；`ZZZZZ` 之类不能套用免检。
- 读音/模板未满足可确定条件时，不能输出确定的“小拗已允许”结论。

### 2.7 三类常见变格（P0 必验）

| 类型 | 最低支持形式 | 条件 |
|---|---|---|
| 孤平自救 | B 型五言 `ZPPZP`；七言对应尾部 | 指出拗位与救位；不能把所有 B 型偏离都算已救 |
| 特拗 | C 型五言 `PPZPZ`；七言“中仄平平仄平仄” | 匹配完整审核模式及约束；认可后不重复硬报；不得换成另一句型免检 |
| 对句相救 | 五言 `ZZPZZ / PPPZP`；七言出句第 6 字 ↔ 对句第 5 字 | 必须同联（出句+对句），不能跨联配对；位置正确只是必要条件 |

- 七言对句相救的合成测试候选可先记录常格前缀 `PPZZPZZ / ZZPPPZP`（仅用于说明第 6/5 字位置对应，属待核定测试材料，不代表已审核真实诗例，也不据此推广前缀或其他变体）。
- 已救时保留原偏离证据，用 `resolvedBy` 指向规则卡 ID，相关 finding 互相关联；不得把原偏离继续作为未解决 error 送汇总。
- 更宽跨句救法、罕见救法不在 P0；未在审核范围内的特殊格式不自动认可。

### 2.8 对仗边界

- P0 提示律诗颔联/颈联需要对仗；简单同位重复或词类信息只作辅助，不宣称完整语义判断，不硬编对仗置信分。

## 3. 正反例速查

| 场景 | 期望 |
|---|---|
| 候选 {P,Z} 在只允许 Z 的必检位 | uncertain，不择合律读音 |
| 韵部集合 {甲,乙}、{乙,丙}、{甲,丙} | 两两相交但全体无交 → fail（RHYME.COMMON） |
| 甲字候选 P/乙部 与 Z/甲部，另一韵脚 P/甲部 | fail，不跨候选拼接 |
| 甲字候选 P/甲或 P/乙，另一韵脚固定 P/甲 | uncertain（部分读法同韵） |
| 一个韵脚未收录 | 不得删除该韵脚后宣布同韵 → uncertain |
| A 型 `ZZZPZ`（五言第三字变仄） | 目标字位 pass/info，resolvedBy=null，不强制对句救 |
| A 型 `PPZZZPZ`（七言第五字变仄） | 对应七言第五字 pass/info |
| A 型第四字（七言第六字）也变仄 | 不适用“小拗允许”免责，另按偏离/救法处理 |
| `ZPZZP` / `ZPPZP`（B 型） | 前者窄义孤平；后者自救并保留拗位/救位与依据 |
| `PPZPZ`（C 型） | 经核定特拗可识别；不重复报被认可位置失对；不得换句型免检 |
| C 型 `PPZZZ` | 三仄尾 warning，不单独令全篇 fail |
| 末三字 PPP | 三平尾 error |
| 真正已救的五言同联 A/B 模式 | 普通偏离与救法诊断关联，resolvedBy 指向规则卡 ID |
| 相同声调形状但跨联、或救位未知 | 不宣称确定的对句相救 |
| 多模板并列未选定 | 待确认；只输出跨候选共同诊断，不静默取首项 |
| applicability=not_applicable | 无近体硬错误，保留查询/归部信息 |
