## 一、《静夜思》：版本决策（本次最急项）

### 决定

**采用《唐诗三百首》系统正文，作为本项目的金标准正文。**

```

举头望明月，低头思故乡。
```

- 指纹：`9d68fef608c1ae6010cfc3ddd7fb2429e60a861bab8c6453874c2adb16d0bdef`（20 字）
- 体裁：`formFamily = ancient`，`formId = null`，`historicalTags = ["古绝", "五言古体"]`
- 近体适用性：**`not_applicable`**（古绝不按近体规则报错；见 `packages/genre/src/classify.ts` 规则 2/3）

### 理由

1. 与项目既有金标准文本一致（`tests/golden/cases/jingyesi.json` 一直是这个正文），改版本会牵动已建立的断言与前端演示数据。
2. 这是课本、选本与大众认知一致的通行文本，教学场景下用户预期最稳。
3. 另一系统的差异集中在首句与第三句的两个字，属**异文**而非错字，不该二选一后丢弃另一方。

### 登记异文（不合并）

宋刊《李太白文集》系统：


- 两者字数相同（各 20 字），但**字形不同 ⇒ 指纹必然不同**，`approvedTextFingerprints` 只登记采用版本，异文版本不登记；
  若将来要支持异文识别，必须另立 `work:jingyesi-songkan` 条目，不得把两个指纹塞进同一条记录。

## 四、与指纹相关的硬约束

| 约束                     | 依据                                                                 |
| ------------------------ | -------------------------------------------------------------------- |
| 只登记采用版本的指纹     | `approvedTextFingerprints` 用于精确命中，混入异文会导致误判          |
| 不做简繁转换             | 简繁差异会改变字形 ⇒ 必须算作不同指纹、不同条目                      |
| 异文各立条目             | 同一作品多版本不得塞进同一条记录，否则命中多条时只能返回 `uncertain` |
| 正文字符数不等于指纹唯一 | 三首里两处异文均与正文同字数，靠字数无法区分                         |
