## 使用边界

1. 本目录数据**全部 `unverified`**，不得加载为可用元数据，也不得据此宣称体裁已审核。
2. `classifyGenre` 只信任 `reviewStatus=approved` 且指纹精确命中的条目；`unverified` 一律不参与判定。
3. 正文来源目前只有**版本系统名**，没有版次/页码，因此 `evidenceIds` 为空——**不编造出处**。
4. 异文必须另立条目（不得把两个指纹塞进同一条记录）；否则精确匹配会退化为“多条命中→`uncertain`”。
