## 使用边界

1. 本目录数据**全部 `unverified`**，不得加载为可用元数据，也不得据此宣称体裁已审核。
2. `classifyGenre` 只信任 `reviewStatus=approved` 且指纹精确命中的条目；`unverified` 一律不参与判定。
3. 正文来源**已定位（维基文库 oldid）但字节未留存**：`data/raw/` 无副本、`data/sources/manifest.json` 无记录、
   没有 `ev:` ID，因此 `evidenceIds` 为空。**不得写成「已核对」**。
4. 异文必须另立条目；否则精确匹配会退化为「多条命中 → `uncertain`」。
5. 「宋刊」这一版本系统名未核实到具体刊本/卷次，一律标**待验证**。
